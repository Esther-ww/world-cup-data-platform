## 3 发现与交接事项

1. **无阻断问题**。A 的模块通过其自测，权限检查在服务端执行，收藏按用户隔离，下载使用固定白名单。
2. **集成注意 1：球队主键**。A 的收藏依赖 `teams(id)` 与只读视图 `a_team_catalog(id,title)`。
   C 的 `teams.id` 在演示库中为 1–8；集成时必须保证 B 的赛程、A 的收藏和 C 的球队使用同一套 id。
3. **集成注意 2：账号复用**。C 的独立演示使用占位 `users` 登录；合并时删除 C 的登录实现，
   直接复用 A 的 `users`、会话与 CSRF。C 的后台只读取 `$_SESSION['uid']` 和 `users.role`。
4. **集成注意 3：时间字段**。A 的留言时间使用数据库 `CURRENT_TIMESTAMP`；C 的比赛时间以 UTC 字符串存储，
   页面统一标注 UTC。合并时如需统一时区展示，应在 B 的赛程模块集中处理。
5. **建议**：合并后补一次联合回归：A 登录 → 收藏 C 的球队 → C 后台修改球队名称 → A 个人中心显示更新；
   以及普通用户直接 POST C 的后台接口应得到 403。
